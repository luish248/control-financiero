Versión base del proyecto para despliegue en Vercel.

Estructura aprobada: Inicio, Movimientos, Pagos, Deudas, Patrimonio, Inversiones, Reportes y Configuración. Patrimonio separa terrenos, maquinaria/equipos, vehículos y otros bienes; Inversiones permanece como módulo independiente.
